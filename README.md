# 🌸 Flower Festival (2D OpenGL Game)

![Project Banner](Assets/menu.png) <!-- استبدلي مسار الصورة بصورة واجهة اللعبة لديك إن وجدت -->

A 2D interactive graphics and arrangement game built with **C++** and **OpenGL (GLUT)**. Players navigate through aesthetic botanical displays, manage flower selections, and interact with custom 2D transformations.

---

## 🎮 Game Overview & Features

* **Interactive Start Screen:** Developed an engaging main menu scene to launch the experience.
* **Vase & Flower Selection:** Interactive scenes for choosing unique vases and arranging flowers precisely inside them.
* **Dynamic Transformations:** Full implementation of 2D geometric transformations including **Translation**, **Scaling**, and **Rotation** on graphical primitives.
* **Multimedia Integration:** Enhanced atmosphere utilizing texture mapping and sound effects.

---

## ⌨️ Controls

| Input | Action |
| :--- | :--- |
| **Mouse Left-Click** | Select Vases / Choose Flowers |
| **Arrow Keys / Drag** | Rotate & Scale Selected Objects |
| **R Key** | Reset / Restart Arrangement Scene |
| **ESC Key** | Exit Application |

---

## 📐 Technical & Graphic Highlights

* **2D Transformations:** Applied matrix transformations for scaling, translating, and rotating objects seamlessly.
* **Matrix Operations:** Utilization of isolated matrix stacks (`glPushMatrix` / `glPopMatrix`) to ensure independent object behaviors.
* **Texture Mapping:** Integrated custom textures for enhanced visual depth and environment rendering.

## 🚀 How to Run

1. Open the project solution in your C++ IDE configured with OpenGL/GLUT.
2. Ensure image assets and header files are placed correctly within the project working directory (`Assets/`).
3. Compile and run the main source file.
